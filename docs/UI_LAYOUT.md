# 界面与保存方式

本文对应 0.5.1 功能基线。完整功能概览见 [README](../README.md)。

## 页面地图

| 侧栏入口 | 地址 | 内容 |
| --- | --- | --- |
| 配置向导 | `#setup` | 首次配置、连接检查和按需功能教程；完成后仍可重新进入 |
| 工作台 | `#overview` | 服务状态、启动操作、诊断和最近动态 |
| 聊天 | `#chats` | 允许范围、详情、人格与模型、任务和用量 |
| 人格 | `#roles` | 人格卡编辑、导入、分类与使用位置 |
| 能力 | `#extensions` | DSH 来源、联网阅读、插件导入、参数与权限 |
| 插件与聊天 | `#plugins` | 直接选聊天并勾选插件，无需进入二级页面 |
| 音乐 | `#music` | 登录、搜歌、音源检查、曲库和声音工作室 |
| 发送模式 | `#sending` | 前台与 Hook 选择、能力对照和组件检查 |
| 表情包 | `#stickers` | 图库、收集、来源、发送与诊断 |
| 记忆 | `#memory` | 群友/人物记忆、日记和上下文摘要 |
| 记忆星图 | `#constellation` | 三维记忆关系、事件时间线和演示星系 |
| 设置 | `#settings` | 默认行为、管理员、连接、诊断、日志与外观 |

“返回上一页”用于控制台内部导航。旧链接如 `#connections`、`#tools`、`#logs` 仍映射到相应设置分类。页面记录滚动位置；向导切换只更新右侧内容，保持左侧导航与滚动。支持的浏览器使用视图过渡；启用“减少动态效果”时减少或关闭动画。

所有页面共用圆角外框。宽窗口持续显示左侧导航，记忆星图填满右侧工作区。窄窗口可用左上角按钮打开导航，点击关闭按钮或按 Esc 收起。外观里的主题和壁纸会应用到外框。

工作台右上方显示连接状态，原连接状态卡的位置显示当前人格。设置分类统一放在内容顶部横排；窄窗口可横向滚动分类，不再切换为左侧竖排，原有分类链接与保存方式保持一致。

## 哪些地方需要保存

| 操作 | 保存规则 |
| --- | --- |
| 全局设置、聊天允许范围 | 使用“保存设置” |
| 某个聊天的人格、模型、模式与授权 | 聊天 → 设置此聊天，独立保存当前聊天 |
| 插件参数与权限 | 能力目录打开插件配置，按面板按钮保存 |
| 插件与聊天页勾选 | 逐项自动保存当前聊天范围；不自动补授权限 |
| 音乐页声音设置 | 点击“保存声音设置”，沿用声音插件同一份参数 |
| 自定义音色、语音来源 | 各区域独立保存，以区域按钮及提示为准 |
| 表情导入、标签与删除 | 操作后立即保存，不依赖全局保存 |
| 配色与背景偏好 | 外观区域自动保存，独立于聊天设置 |

跳转和试听均不代替保存。未保存提示出现时，先确认草稿再决定去留。保存成功表示配置已写入，不等同服务已连通或真实发送通过。

## 聊天与插件的分工

“聊天”管理允许范围及人格、模型、模式、群聊参与方式和工具授权。“插件与聊天”在同一页先选群聊/好友，再分配已安装插件；缺少必需权限时应先打开参数配置，不通过勾选扩大权限。

“能力”保留插件安装、参数、权限和原有聊天范围管理，也展示 DSH 工具来源。WeChatGirl ZIP 插件与 DSH 插件分别安装，不共用启用开关。

## 音乐与桌面操作

歌曲以歌名气泡显示，悬停、键盘聚焦或点按查看详情。桌面版“打开文件位置”仅定位当前账号曲库中已登记的歌曲。其他登录选项在页内展开；自定义音色默认折叠、首次展开读取，收起保留编辑内容。

更多菜单和托盘均提供一键启动、重启服务和重启程序。重启程序先检查未保存修改，再停止本实例服务。关闭窗口收起到托盘；退出程序保留外部微信和 DSH。只读诊断与明确标注的测试发送按钮分别处理，打开页面不会自动发微信消息。

## 外观

支持浅色、深色、预设配色、自定义颜色与桌面背景；窄窗口使用可展开导航和单列布局。桌面偏好跨端口保留；浏览器偏好属于当前源地址，不同端口不保证共用。外观保存与聊天配置草稿独立。
