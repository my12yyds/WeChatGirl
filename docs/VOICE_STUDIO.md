# 声音工作室：语音、音色与唱歌

大型本地环境已从主包拆出，可在“音乐 → 语音组件管理”下载并直接导入 ZIP，无需手动解压。环境包不包含全部模型，导入后继续核对引擎与服务状态，详见[语音组件导入](VOICE_COMPONENTS.md)。

声音功能由“肥鱼声音工作室”插件和宿主音频服务共同提供。音乐页管理曲库和翻唱任务，独立的“语音音色”页管理声音参数、音色和引擎；“能力 → 能力目录”保留插件安装、权限和聊天范围。插件需要 storage / voice 权限，实际发微信还要求 Hook 模式与原生语音能力就绪。

## 先确认依赖

默认说话调用本机部署的 Breeze TTS 服务；肥鱼换声使用本机 RVC。分离伴奏、翻唱及歌词配谱分别需要对应模型和独立环境。宿主通过 `scripts/voice-services.ps1` 管理本机服务。

**插件 ZIP 只提供插件代码，可选语音组件也不等于全部模型。**模型、参考录音、账号音色、队列与歌曲位于 `state/voice/`，不随源码或插件包发布。新电脑需要自行准备匹配环境和获准使用的模型，不能把开发机已验证当作所有安装版开箱可用。

## 语音回复与随机替换

可明确要求“用语音说晚安”。内置音色有 B 明亮可爱、A 自然可爱和温柔版，支持聊天内选择。文字长度、音频时长、发送额度和最短间隔均会限制请求；单段原生语音最长 60 秒。

“语音音色”页可开启**随机用语音替换部分句子**，设置概率与冷却。每轮最多替换一句；制作失败时补发原句文字。另有全部短回复附带语音选项，以页面提示的优先关系为准。这是“是否发语音”的随机，与“使用哪个音色”的随机分别配置。

“发送节奏”控制同一聊天的间隔、每分钟及十分钟额度。等待制作、额度和发送锁是不同阶段，不能仅凭“已生成”判断卡住。需要保留肥鱼音色时开启额外换声，关闭能减少处理但声音会变化。

## 自定义与随机音色

自定义音色默认折叠、首次展开加载，收起保留未保存编辑。支持新增、复制、命名、删除和选择默认。参考录音为 1–30 秒，配准确参考文字；本机整理为单声道 24 kHz WAV。

可调整语气指令、音调 0–5、语速 0.75–1.25 倍、额外肥鱼换声，以及音量 0.5–1.5、低音/高音 ±6 dB、响度均衡、首尾静音裁剪。本地高级生成参数包括引导强度、变化程度及种子。上传参考影响说话，**不会自动训练或替换唱歌模型**。

保存后可生成本机试听，不发微信。音色按账号隔离；复制可复用参考录音，删除预设保留旧任务所需文件。新任务保存音色快照，重试不重新抽取或跟随编辑变化。

“随机音色”开启后从选中的内置或自定义候选选择。外接 API 只从填有 API 音色 ID 的自定义预设随机；无有效候选则用默认 API 音色。本机编辑试听固定使用当前编辑音色。

## 本地合成与外接 API

“语音合成来源”默认本地。用户可主动切换到兼容 `/audio/speech`、返回 WAV 的接口，配置服务地址、模型、默认音色 ID 与密钥；支持根地址、含 /v1 的基础地址或完整接口地址。

外接服务会收到待合成文字，可能使用额度；本地参考录音不上传。API 音色 ID 必须由服务商实际提供，不等于上传录音克隆。仅在服务支持时发送语气 instructions。音频滤镜可本机处理，高级采样参数只用于本地引擎。

密钥用 Windows 当前账户 DPAPI 加密；留空保留，明确勾选清除才删除。切换服务不改变旧本地任务来源；外接任务绑定配置版本，变更后需新建请求，避免静默发往其他服务。接口响应大小、请求时间与 WAV 格式均受限，不代表兼容所有语音供应商。

## 唱歌与本机曲库

| 路径 | 输入与处理 |
| --- | --- |
| 已有人声/曲库 | 导入最长 60 秒人声并命名，使用本机换声模型制作 |
| 网易云点歌 | 精确匹配歌名和指定歌手，按账号可用权限读取音源，分离人声/伴奏、换声并按原时间轴混音 |
| 歌词配曲谱 | 提供 ABC 曲谱及对齐歌词，由 SoulX-Singer 生成歌声后换声 |

自动点歌默认制作约 55 秒片段，并非完整长歌。原版、现场与翻唱不任意互换；无准确歌曲、无音源权限或分离失败时明确失败，不另编旋律冒充。完整音源权限见[网易云账号](NETEASE_ACCOUNT.md)。

“清晰人声混音”减少低频和中低频浑浊，适度突出咬字，避免过度提高整体响度；“伴奏音量”调整遮盖。换声人声与曲谱歌声也使用轻量清晰处理，不改变歌曲速度和音高。效果仍取决于源录音、分离质量和模型。新版清晰混音使用新的成品缓存标识，首次需重新制作，旧版本仍保留在曲库中。

## 默认肥鱼语音的听感

“语音音色”页的“自定义音色”提供两个新建预设：**自然直出**使用已有肥鱼参考音频直接克隆，原调、原速、CFG 1，不额外换声或均衡；**明亮换声**额外升调并经过 RVC，音色特点更突出，也可能增加机械感。预设只填入新音色参数，不覆盖已有录音与音色；保存、试听后可设为默认。新建音色默认从自然直出参数开始，旧音色保留原参数。

Breeze 参考克隆继续保留。另外新增“原生肥鱼 CosyVoice3”独立可选插件：需另行准备 TTS 环境与官方肥鱼权重，启用后可在语音音色页面同文本对比或选择专用常驻引擎。本机已独立部署并实际合成；发行插件 ZIP 不包含环境、权重和密钥。自然 A、自定义参考音色与外接 API 继续使用各自配置，详见 [五项进度与配置](P1_P2_PROGRESS.md)。

未选择自定义音色时，本地内置音色采用短中性提示词“自然清晰地说话。”与 `cfg_scale=1`，更多沿用参考录音的节奏，撤掉“舒缓、轻声、停顿”等叠加指令和换声后的 90% 减速。肥鱼换声后仅轻度削减低频和中低频、补充高频，减轻声音过厚，不额外改变语速。参考音频与肥鱼换声模型继续沿用，断点恢复也仅处理一次。

此默认处理只作用于本地内置肥鱼语音，自定义音色与外接语音 API 保留自己的速度和均衡设置。需要个人调整时，在“语音音色”页的自定义音色中设置语速、音调、低频及高频后试听保存。音色接近程度取决于参考素材和模型，不能保证与原声完全一致；限长仍为 60 秒，超限会明确失败，不截掉结尾。

调参依据：[Breeze-TTS-2.cpp v0.1.6 API](https://github.com/HoppouAI/Breeze-TTS-2.cpp/blob/v0.1.6/docs/server.md) 的默认 CFG 为 1；[Breeze 官方说明](https://github.com/breezeblue-ai/breeze-tts#usage) 区分参考克隆与风格引导。默认使用普通参考克隆，自定义音色仍可主动提高引导强度；引导越强不代表越自然。该选择需结合本机试听判断，自动测试只能验证参数和音频完整性。

参考方案：[肥鱼原生 TTS 与 RVC 分工](https://github.com/Esmerubphire/astrbot_plugin_feiyu_voice/blob/main/server/README.md)、[GPT-SoVITS 的参考克隆与少样本微调](https://github.com/RVC-Boss/GPT-SoVITS)。直接克隆可减少转换环节，但自然度与声音相似度仍需分别试听，不能用耗时或测试通过数代替听感判断。语音服务的“生成本机试听”使用当前选中的默认音色；随机音色不会在此试听中随机抽取。

成功成品保存到本机，同账号相同歌曲、音色与制作参数满足缓存条件时复用。音乐页自动刷新曲库，以歌名气泡展示；悬停、聚焦或点按查看详细版本。桌面版可打开已登记文件位置，不接受任意文件路径。

## 进度、取消与送达

任务显示真实的查找音源、分离、合成/换声、混音编码、等待发送及回执状态，不提供虚构百分比。唱歌通常比说话重，硬件和首次模型加载会影响耗时，本机旧测试用时不作为速度承诺。

“取消语音”“停止唱歌”用于取消本聊天尚未提交的申请；已经交给微信的动作不承诺撤回。模型工具先申请，本轮成功且未取消后才建立持久队列。账号、权限、插件代次及聊天范围变化会阻止过期申请发送。

生成完成、接口接受和服务器回执确认分别记录。请求在调用原生接口前落盘；响应丢失时核验已绑定的消息与音频摘要，不盲目重新发送。证据不足保留未确认。最终是否可播放仍以收件端为准。

## 测试与许可

本机试听不发微信；“发送测试语音”会向明确选定的已授权聊天发送，需用户主动操作。隔离回归覆盖队列、去重、权限、音色快照、缓存与外接协议；不代表所有机器或真实外接服务均验收通过。

## 独立音色页面与本地模型

侧栏“语音音色”集中管理语音组件、服务来源、参考音色和声音插件；“音乐”保留网易云登录、搜索及本机曲库。声音插件 1.3.1 的完整设置支持本地 Breeze TTS 2 兼容 GGUF 路径，留空沿用默认模型。保存后重启语音服务才加载新路径。其他模型架构需单独引擎，可使用兼容语音 API。

“语音音色 → 选择本地声音模型”也可单独配置设备级本地模型插件，无需覆盖已有声音插件代码。此设备级插件启用时优先采用所选路径，关闭后回到声音插件原配置或内置模型。原生语音发送仍需声音插件自己的权限和聊天范围。

## 保存默认音乐方式

音乐页的“歌曲发送方式”可选择1分钟片段或完整翻唱，再点击“保存为默认方式”。不保存只影响本次页面点歌；保存后普通聊天点歌沿用。聊天里明确要求“只唱一分钟”或“完整唱一遍”会临时覆盖，任务入队后不随默认设置改变。片段在分离前裁取最多60秒，整首则按每段最长55秒发送；详细限制与例子见 [新功能说明](NEW_FEATURES_GUIDE.md)。

## 音乐制作故障修复与进度

整首歌曲先按短片段分离，换声前转为24kHz单声道并分段上传；不会再把整首立体声WAV一次提交给16MB限制的服务。转换使用相邻上下文并裁回原位置，混音后才按最长55秒编码发送。片段模式仍先截取最多60秒，最后只发送一条。

制作状态显示分离或换声的当前段/总段数。转换完成的中间片段会在本机校验后复用；模型、音频或相关参数变化会使用不同缓存。内存不足会明确提示，不会把制作失败显示为已发送。修复不会自动重发旧失败或送达不明的任务；更新后请重新点歌。

人声分离工作进程关闭 ONNX Runtime 的 CPU 内存池预留与内存模式预分配，并限制推理线程，减少与 DSH、语音模型同时运行时的内存峰值；不改变歌曲时长、模型权重或伴奏对齐。原生 ONNX/PyTorch 内存分配错误也会识别为内存不足，而非笼统的分离失败。选项含义见 [ONNX Runtime 官方说明](https://onnxruntime.ai/docs/api/python/api_summary.html)。

CosyVoice 服务启动时只准备接口与检查音色文件，首次实际合成才加载模型；第一次试听会包含模型加载时间。健康接口的 `modelLoaded` 表示模型是否已经加载。维护时可使用 `voice-services.ps1 -Action start-singing` 只启动唱歌服务，避免同时启动其他声音模型。

## 来源与音色配置（界面调整）

语音音色页先选择本地模型或外接API。本地可使用随附肥鱼引擎，或通过“选择自己的模型”配置 Breeze TTS 2 兼容 GGUF 文件；其他模型格式不能直接使用。模型自带音色与自定义录音采用选项卡切换，不用折叠区域。内置音色提供明亮可爱、自然可爱、温柔，可填写最多100字试听。

外接API单独填写模型和音色ID，可维护最多100个服务音色ID（每行一个），在音色ID输入框选择；不同服务没有统一的音色查询接口，目前为手动维护清单。切换到API会隐藏本地音色库；新合成任务不套用本地参考音色与调音配置。输入试听文本无需再次保存配置。

音乐与语音制作/发送进度分别常驻显示；桌面宽窗口在右侧，窄窗口顺序排列，按任务类型过滤。人声素材导入与曲库合并使用，进度不依赖展开操作。

音乐来源页显示实际接入进度：网易云支持完整搜索、登录与账号可用音源；QQ音乐、酷狗目前仅提供官方入口，完整音源读取和翻唱适配仍待完成。其他平台链接不能当作网易云链接点唱。

群聊中的完整翻唱在首段确认送达后，会艾特身份可核验的点歌人一次。提醒按歌曲任务去重，使用独立于普通回复艾特的投递路径。
