# 从安装到第一次回复

这份教程面向第一次使用 WeChatGirl 的用户。程序内同样提供引导：打开左侧“配置向导”，在“连接微信”顶部展开“从安装到首次聊天的完整教程”。

## 1. 安装并打开程序

1. 从[项目发布页](https://github.com/my12yyds/WeChatGirl/releases/latest)下载安装器，文件名含 `WeChatGirl-Setup`、版本号和 `x64.exe`。
2. 双击安装器，跟随提示选择程序根目录，完成安装后打开 WeChatGirl。升级前先保存设置，从系统托盘完整退出旧程序；安装到原根目录，保留同级 `data`。
3. 如果使用便携 ZIP，先将整个压缩包解压到一个可写的文件夹，再双击根目录 `WeChatGirl.exe`。不要在压缩包里直接运行，也不要只复制一个 EXE。
4. 首次启动会进入“配置向导”。运行环境随程序准备，日常使用不需要打开 CMD 或自行安装 Python、Node.js。DSH 需要另行安装。

成功标志：看到 WeChatGirl 的配置向导，而不是停留在安装器中。

## 2. 登录匹配微信

1. 在向导选择“连接微信”，查看“微信版本与内置客户端”。
2. 当前内置匹配版为微信 **4.1.15.13 x64**，支持原生语音和歌曲分段。点击“使用并打开内置匹配版”或“打开匹配微信”，在该微信里登录自己的账号，等待消息同步。
3. 如果提示其他微信正在运行，先保存工作，从它的系统托盘退出，再打开匹配版。不要把关闭窗口当成完整退出，也不要同时反复打开多个版本。

成功标志：匹配微信正常打开，已登录自己的账号，可以看到聊天列表。登录其他版本不等于这个匹配版已登录。

## 3. 在微信设置中找到数据文件夹

1. 留在刚刚登录的微信主窗口，点击左下角菜单，打开 **“设置”**。
2. 找到 **“存储位置”**，查看微信显示的文件存储路径。按当前版本界面找到对应的文件保存位置即可。
3. 如果有“打开文件夹”，点击后，在文件资源管理器顶部地址栏复制完整路径；也可以直接记下设置中显示的路径。
4. 回到 WeChatGirl 的“连接自己的微信”，点击 **“选择文件夹”**，选择刚才看到的存储目录。也可把完整路径粘贴进“微信数据文件夹”输入框，点击 **“识别此目录”**。
5. 程序支持存储目录内常见的 `xwechat_files`、账号文件夹和 `db_storage`。例如设置显示 `D:\微信数据`，里面有 `xwechat_files` 时，可直接选择 `D:\微信数据`；也可继续选择里面的 `xwechat_files` 或自己的账号文件夹。这里只识别指定位置和已知子目录，不会递归扫描整个硬盘。
6. 在 **“当前账号”** 核对刚才登录的账号。找到多个账号时由你选择，不要随便选第一个。
7. 点击 **“一键连接并验证”**，按操作面板提示完成。获取期间保持微信正常登录；只有提示需要时再退出账号并重新登录。

这里选的是**微信保存数据的文件夹**。不要选 WeChatGirl 的安装目录或 `Weixin.exe` 所在的程序目录。只需查看并选择原位置，不需要修改微信的存储位置、移动文件或删除原数据。

成功标志：“连接自己的微信”显示 **“已验证”**。选择了文件夹、找到了账号，都不等于数据库已经验证成功。

找不到账号时：先确认所选目录与微信设置一致、匹配微信已登录且消息同步完成，再点击“识别此目录”。“自动查找账号”是辅助入口，自定义存储位置优先按微信设置手动选择。不要把数据库密钥、账号目录内容或完整日志发给别人。

## 4. 安装 DSH 并加载本机插件

1. 在向导点击“连接 DSH”，通过页面的“打开官方下载页”下载安装 DSH；已有 DSH 可继续使用。
2. 打开 DSH 一次完成初始化。在 WeChatGirl 选择安装目录中的 `DeepSeek Harness.exe`，点击“保存设置”。选择程序文件，不是快捷方式或插件文件夹。
3. 保存 DSH 中未完成的工作，从系统托盘完整退出 DSH。
4. 在 WeChatGirl 点击“一键导入到 DSH”，等待操作面板完成。旧版不支持自动导入时，按页内提示复制插件路径，在 DSH 手动添加并启用。
5. 重新打开 DSH，登录或配置自己的模型账号，并确认本机插件启用。启用后若提示重开，按提示从托盘完整退出再打开。
6. 回到向导点击“重新检查”。

成功标志：显示本项目插件已连接。仅出现“导入成功”还不能证明模型和服务已连接。详见 [DSH 连接说明](EXTERNAL_DSH.md)。

## 5. 选择模型和发送方式

1. 进入“选择模型”，刷新 DSH 模型列表，选择自己的账号可用、支持文字对话的模型，然后保存。无需手动填写模型名称。
2. 需要时再配置图片分流；基础文字聊天可以先完成。模型在列表中不代表账号一定有余额或额度。
3. 进入“选择发送模式”，阅读页面的能力差异，选择后保存。前台模式需要微信窗口可操作；原生语音气泡、指定表情、多表情队列等能力需要 Hook 模式及相应组件就绪。

成功标志：模型和发送模式都有已保存的选择。完整差异见[发送模式说明](SENDING_MODES.md)。

## 6. 启动服务，选择允许的聊天

1. 进入“启动服务”，保存尚未保存的设置，再点击“启动服务”或“应用设置并检查连接”。
2. 查看微信读取、消息桥接和模型连接的检查结果。有失败时先返回对应步骤处理，避免重复初始化全部数据。
3. 进入“选择聊天并试聊”，搜索并添加一个明确同意试用的好友，或选择需要机器人参与的群聊。
4. 添加会先进入草稿，点击“保存设置”，再按页内按钮应用并重启服务。
5. 需要独立人格或模型时，进入“聊天 → 设置此聊天”，选择后使用该聊天的保存按钮。

成功标志：目标聊天已保存在允许范围内，所需服务就绪。新安装的聊天允许范围为空，不会自动回复所有好友和群聊。

## 7. 由你完成第一次试聊

1. 让已允许的好友发一句“你好”；也可用自己的另一个微信向机器人发送。
2. 群聊先 @ 助手或使用配置的唤醒词，方便确认基础回复。
3. 在微信中确认实际收到文字回复，再测试表情、图片或语音。程序不会替你发送测试消息。

如果没有回复，依次检查：聊天是否在允许范围、设置是否保存并应用、微信是否仍登录、模型是否可用、当前发送模式是否满足窗口或组件条件。不要只凭后台生成了文字就认定消息已经发送。

## 8. 逐个开启可选功能

- 人格：在“人格”管理，在“聊天”分配；编辑后按页面提示保存与应用。
- 表情：在“表情包 → 自动收集”分别开启微信聊天收集和 DSH 入库，可以只开一边或同时开启；DSH 图库接入及聊天授权另行配置。
- 图片分流：在“配置向导 → 选择模型”或“设置 → 微信与 DSH”选择备用识图模型，再按测试按钮说明自行测试。
- 音乐与音色：在“音乐”配置网易云登录、声音来源及音色。缺少本地环境时，在“语音组件管理”下载并直接导入 ZIP，模型和服务仍需检查；原生语音需要 Hook 模式及对应组件。见[组件导入教程](VOICE_COMPONENTS.md)。
- 插件：在“能力”安装并配置参数和权限，在“插件与聊天”选择哪些聊天可以使用。
- 管理员任务：先设置真实管理员，再为目标聊天授权 DSH 能力；普通聊天用户不会自动获得任务权限。

每次只增加一项，保存后验证，再继续配置下一项。可选功能可跳过，之后从配置向导随时返回。

## 日常打开、退出和更新

下次使用时打开 WeChatGirl、匹配微信和 DSH，确认登录正常，再从工作台或托盘“一键启动”。关闭窗口通常收起到托盘；需要完全退出时使用托盘的退出菜单。更换账号、模型或聊天范围后，按页面提示保存和应用。

更新前保存设置、完整退出旧程序和 DSH，保留 `data`，再安装新版。需要卸载时使用 Windows“已安装的应用”或程序提供的卸载入口；不要把删除数据文件夹作为排障步骤。
