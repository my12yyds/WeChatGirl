# 肥鱼声音工作室

版本：1.4.1 · 可选插件，按需安装

[返回插件目录](README.md) · [下载单独插件包](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.7/voice-studio-1.4.1.zip)

## 适合做什么

语音回复、音色切换与翻唱任务入口，和语音音色页、音乐页共用宿主服务。

申请微信语音气泡与歌曲制作，支持自定义和随机音色、部分句子随机改发语音、伴奏分离及成品复用。默认调用本地部署，需准备模型与发送组件；语音音色页可选本地兼容 GGUF 模型或外接语音 API。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 先在语音音色页配置本地服务或外接API；原生微信语音还需Hook模式、声音权限和聊天授权。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重开DSH。

## 使用例子

“用语音说晚安”“只唱这首歌一分钟”“完整唱一遍，分段发送”“唱歌进度”。

## 权限与数据

- 保存插件数据
- 在已授权聊天发送原生语音与歌曲

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 限制与排查

本地运行环境和模型另行准备；外接TTS不替代本地翻唱引擎。完整翻唱当前上限10分钟。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后从托盘完整重开DSH。
- 模型或本地环境报错：先在对应功能页做连接检测或本机试听，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
