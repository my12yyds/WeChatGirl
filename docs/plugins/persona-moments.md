# 人格定时朋友圈

版本：0.3.1 · 可选插件，按需安装

[返回插件目录](README.md) · [下载单独插件包](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.7/persona-moments-0.3.1.zip)

## 适合做什么

按人格及计划准备朋友圈内容，管理自动化发布流程。

按当前人设定时总结当天聊天，通过本机Python组件填写或发布纯文字朋友圈；支持管理员在私聊里直接发布，以及把重大事件先提交为候选、由管理员确认后再发布。需先安装Python运行环境；默认预览不发布。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 先配置人格、计划时间与所需权限；发布前检查当前发送模式和微信组件能力。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重开DSH。

## 使用例子

先用测试计划检查内容和状态，再启用正式计划。

## 权限与数据

- 保存插件数据
- 读取当前聊天历史
- 读取当前聊天人格
- 独立调用当前模型（会产生消耗）
- 按设置的每日时间执行

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 配置选项

| 配置 | 默认值 | 范围或选择 | 说明 |
| --- | --- | --- | --- |
| 每日北京时间 HH:MM | "21:30" | 最多5字符 | 设为00:00时总结前一天的聊天；其他时间总结当天。电脑、微信与DSH需保持运行。 |
| 运行模式 | "publish" | draft / preview / publish | draft只存草稿；preview填好后暂停；publish自动点击发表，需先测试。 |
| WeChatGirl workspace 绝对路径（通常留空） | "" | 最多500字符 | 留空按安装目录推导；必须含config/wechatagent.json与state。 |
| Python绝对路径（安装运行环境后可留空） | "" | 最多500字符 | 默认使用兼容数据目录 LocalAppData/WeChatAgentMoments/runtime/Scripts/python.exe；目录名是既有本机数据标识。 |
| 管理员私聊 key（建议填写） | "" | 最多60字符 | 如 wechat:private:你的管理员微信ID；留空时只允许任意私聊，填写后只有该聊天能发布或确认。 |
| 候选有效期（分钟） | 120 | 5–720 | 超过后候选自动失效，需要重新提议。 |
| 每天最多发布条数 | 1 | 1–3 | 所有聊天与人设共享；默认1条，最多3条。 |
| 允许把重大事件提交为候选 | true | 开 / 关 | 关闭后模型只能预览和定时任务，不能提议。 |

## 限制与排查

发布涉及真实微信账号；请核对权限、计划时间和当前组件兼容性，不把“已生成”当作“已发布”。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后从托盘完整重开DSH。
- 模型或本地环境报错：先在对应功能页做连接检测或本机试听，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
