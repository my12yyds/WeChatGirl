# 本地声音模型

版本：1.0.0 · 可选插件，按需安装

[返回插件目录](README.md) · [下载单独插件包](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.7/local-voice-model-1.0.0.zip)

## 适合做什么

选择本机兼容Breeze TTS 2的GGUF模型文件。

选择现有本机 Breeze TTS 2 兼容 GGUF 模型。只影响本机合成服务启动，保存后重启语音服务。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 在语音音色页选择本地模型绝对路径，保存后重启语音服务。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重开DSH。

## 使用例子

选择兼容GGUF后先生成本机试听，确认效果再用于聊天。

## 权限与数据

不申请额外聊天权限；实际发送仍由声音插件及宿主授权控制。

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 配置选项

| 配置 | 默认值 | 范围或选择 | 说明 |
| --- | --- | --- | --- |
| 本地 Breeze 模型文件 | "" | 最多500字符 | 绝对路径，留空使用内置模型。仅支持 Breeze TTS 2 兼容 GGUF；保存并重启语音服务后生效。 |

## 限制与排查

留空沿用默认位置；其他架构的模型不能仅改文件名加载，模型不包含在插件ZIP中。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后从托盘完整重开DSH。
- 模型或本地环境报错：先在对应功能页做连接检测或本机试听，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
