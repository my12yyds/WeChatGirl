# 跨聊天人物记忆

版本：1.3.0 · 基础插件，随主包提供

[返回插件目录](README.md) · [下载单独插件包](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.7/people-memory-1.3.0.zip)

## 适合做什么

记住长期偏好、昵称、宠物、项目与约定，并按真实身份区分同名人物。

按真实微信身份管理人物事实、自动召回与滚动摘要；可配置记录类型、有效期、容量、上下文及摘要节奏，并按聊天授权。

### 记忆星图

星图可查看人物记忆、聊天事件、群友观察、已保存的聊天摘要和日记。按类型或聊天筛选后，使用「上一批」「下一批」查看更早的记录。点击一颗星可以看到同一人物、同一聊天或同日同类事件的关联，关联条目可以直接打开。人物关联使用已有的微信身份记录。同名不会自动合并；同日同类只表示可能相关。群友观察、日记和摘要可回对应页面查看来源。

星系包含有厚度的旋臂、立体星核和稀疏星晕。向上或向下拖动可改变观察角度，也可以用「俯视」与「侧视」查看星盘。渲染参考 [Three.js 透视相机](https://threejs.org/docs/pages/PerspectiveCamera.html) 和 [点精灵示例](https://threejs.org/examples/#webgl_points_sprites)，本项目用 WebGL 绘制点云，硬件加速不可用时用 Canvas 保留透视。

点「演示星系」可查看 6 个虚构人物的 48 条聊天示例，包括三种事件进展、失效记录和已召回的记忆。演示筛选和置顶只在当前页面有效，退出后恢复真实星图。

旋转、拖动和缩放会同时作用于星系和记忆星点。每条记忆对应一颗可点击的主星，周围的彩色星尘是该记录的视觉效果。颜色区分记忆类型，也区分已约定、已发生、已取消和失效记录。置顶是最大的核心星，最近召回、待履行的约定及部分长期人物资料是重要星。查看详情可确认分级依据，也可用「置顶」提升一条记忆的显示等级。

打开星图后，左侧保留导航，图面铺满右侧工作区。默认「特效」显示缓慢旋转的星河、星点光晕和连线粒子。可用图底部的「缓慢旋转」暂停动画，或在顶部切换「极简」，选择会保存在当前浏览器。系统启用减少动态效果时，星河保持静止。用「筛选」和「记忆列表」展开相应面板，点击星点直接打开详情，点「返回」离开星图。

主程序升级后，从侧栏打开「记忆星图」。在「关系星图」中拖动或缩放，悬停时会高亮同一人物的记忆。选择星点或右侧列表可看内容、来源、有效期和共享范围，也可置顶。「事件时间线」按事件日期分组，可筛选已约定、已发生和已取消。通过「记忆 → 人物与事实」可纠正、忘记或恢复条目。

星图只展示当前允许范围内的来源记录。切到某个聊天时，来自别处的记忆只有在本人允许共享、来源仍授权且确实在该聊天被召回时才会出现。星环表示最近一次召回选中的记忆，实际加入模型上下文还受长度预算限制。新版 DSH 桥接重开后，新的召回会留下星环。星图浏览本身无需模型调用。

图谱的交互参考 [Obsidian Graph View](https://obsidian.md/help/plugins/graph) 与 [Sigma.js](https://github.com/jacomyal/sigma.js)。事件、时间与来源的组织参考 [Graphiti](https://github.com/getzep/graphiti) 与 [Mem0](https://github.com/mem0ai/mem0)，本项目沿用本地人物记忆存储和原有授权。

### 自动记录聊天事件

在「记录设置」启用人物记忆，授权要使用的聊天，并打开「自动记录本人事实」和「自动记录明确计划」。例如，「明天我们去露营，说定了」会记录为已约定，「昨天我去看电影了」会记录为已发生。原发言者后续说「明天的露营取消了」，同一聊天中能唯一匹配到那件事时会更新为已取消。相对日期按发言时的北京时间计算。

聊天模式收到消息后在本机识别事件，普通群消息无需唤醒或回复也可以记录。规则仅处理表述明确且能核对发言者的消息，疑问、假设、引用、转发和明确拒绝记录的内容会跳过。当前识别以单条消息中的明确线索为主，不回扫旧记录。事件留在来源聊天，自动提取本身无需调用模型。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 先授权人物记忆并选择聊天，再在记忆页检查来源、纠正错误；跨聊天共享仍需本人同意。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重开DSH。

## 权限与数据

- 按真实身份保存跨聊天记忆

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 限制与排查

昵称、事实、短期计划期限分别设置；不能保证所有模型每次都正确回忆。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后从托盘完整重开DSH。
- 模型或本地环境报错：先在对应功能页做连接检测或本机试听，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
