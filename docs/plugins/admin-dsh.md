# 管理员 DSH 助手

版本：1.1.0 · 可选插件，按需安装

[返回插件目录](README.md) · [下载单独插件包](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.7/admin-dsh-1.1.0.zip)

## 适合做什么

让已授权管理员从聊天调用DSH任务。

管理员在聊天或助手模式中按本聊天授权调用 DSH，支持能力查询、任务进度、结果与取消。聊天模式保留人格和历史，默认关闭调用权限。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 先在助手设置中用真实微信账号指定管理员。到“DSH 权限”选择要授权的好友或群聊，开启聊天模式执行，并勾选所需的工具和技能后保存。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重开DSH。

## 使用例子

管理员可以在已授权的私聊或群里发送 `/dsh 查看当前工作区有哪些项目`，也可以说“调用 DSH 查看当前工作区有哪些项目”。群里即使设置为仅被 @ 才回复，管理员也可以直接发送这类命令。命令独立处理，群友的插话不会成为同一轮任务。

任务使用本聊天已授权的工具和技能。需要 DSH 本机审批时，请到 DSH 界面确认。群聊中的执行结果会回复到原群，涉及私密内容时请在已授权的私聊交办。

## 权限与数据

- 管理员调用 DSH 任务

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 配置选项

本插件没有独立参数；按权限和聊天范围控制。

## 限制与排查

任务可能产生文件写入或外部操作；插件不会让普通群友自动成为管理员。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后从托盘完整重开DSH。
- 模型或本地环境报错：先在对应功能页做连接检测或本机试听，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
