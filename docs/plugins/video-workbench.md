# 视频压缩与识别

在「能力目录」安装视频插件，然后启用并选择授权聊天。保存后重新打开插件配置，在「视频工作台」选本地视频。完整操作步骤见[插件说明](../../optional-extensions/video-workbench/README.md)。

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 压缩分辨率上限 | 720 | 按原比例缩小，可选 480、720、1080 |
| 压缩强度（CRF） | 26 | 范围 20–34，数值越高，输出通常越小 |
| 识别抽帧数量 | 6 | 可选 4、6、8，帧按视频播放顺序排列 |
| 视频识别模型 | 跟随聊天与图片分流 | 从 DSH 目录选择独立识图模型。手动选择只影响视频，保持原聊天和图片模型设置 |

工作台显示输出体积。较短或已经压得很小的视频转码后可能变大。识别需要 DSH 与可用的识图模型，压缩只依赖本机 FFmpeg。首次升级宿主后，从托盘完整重开 DSH。
