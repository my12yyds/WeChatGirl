# 虚构长对话评测

版本：1.0.1 · 可选插件，按需安装

[返回插件目录](README.md) · [下载单独插件包](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.7/memory-evaluation-1.0.1.zip)

## 适合做什么

用虚构长对话检查回忆、纠正、同名隔离与跨聊天隐私。

用固定虚构人物和100/500条消息检测旧事召回、昵称纠正、同名分离、跨群隐私与拒绝共享。分别评估资料召回和模型回答，不读真实聊天，不发微信；会调用当前选择的模型并消耗额度。测试通过只代表这些固定案例，不保证所有聊天永远记得。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 开启评测许可，选择允许的聊天和模型，确认额度后运行。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重开DSH。

## 使用例子

在记忆评测页分别运行100条和500条案例，区分召回评分与回答评分。

## 权限与数据

- 独立调用当前模型（会产生消耗）

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 配置选项

| 配置 | 默认值 | 范围或选择 | 说明 |
| --- | --- | --- | --- |
| 允许模型评测（产生模型额度消耗） | false | 开 / 关 | 默认关闭。开启只是允许运行固定虚构评测，不会自动开始；执行时仍需明确确认。评测会使用所选聊天模型的额度，结果不写入真实人物记忆。 |

## 限制与排查

会调用当前模型并产生消耗；不读取真实聊天当测试集，不向微信发送评测消息，固定案例通过不代表所有场景都正确。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后从托盘完整重开DSH。
- 模型或本地环境报错：先在对应功能页做连接检测或本机试听，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
