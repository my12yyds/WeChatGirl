# 网易云音乐

版本：1.1.0 · 可选插件，按需安装

[返回插件目录](README.md) · [下载单独插件包](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.7/netease-music-1.1.0.zip)

## 适合做什么

通过网易云站内搜索与链接读取找到准确的歌曲版本。

网易云站内搜索歌曲、读取歌曲与公开歌单。音乐工作台支持扫码登录，后台按账号实际权限读取音源；登录凭据只保存在本机，不交给聊天模型。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 需要账号权限时在音乐页用官方窗口登录；登录凭据仅由本机管理。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重开DSH。

## 使用例子

“搜索邓紫棋的泡沫”，或发送网易云歌曲链接后要求翻唱。

## 权限与数据

- 访问公开网页

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 配置选项

本插件没有独立参数；按权限和聊天范围控制。

## 限制与排查

搜索结果不代表拥有完整音源，会员、版权及试听限制以网易云返回为准。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后从托盘完整重开DSH。
- 模型或本地环境报错：先在对应功能页做连接检测或本机试听，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
