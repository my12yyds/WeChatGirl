# 原生肥鱼 CosyVoice3

版本：1.0.1 · 可选插件，按需安装

[返回插件目录](README.md) · [下载单独插件包](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.7/cosyvoice-engine-1.0.1.zip)

## 适合做什么

选择专用原生肥鱼CosyVoice3，并和Breeze进行同文本试听。

提供专用肥鱼CosyVoice3本机常驻合成，与Breeze参考克隆分开选择。需独立准备模型与环境；插件ZIP不含权重。首次加载较慢，驻留后可复用。它只选择设备引擎，微信发送仍受声音插件权限和聊天范围控制；外接API、自定义参考与自然A保持各自路径。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 单独准备TTS环境和权重；在语音音色页配置引擎并重启语音服务。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重开DSH。

## 使用例子

先保持Breeze，开启本机对比试听；喜欢专用音色后再切换CosyVoice3。

## 权限与数据

不申请额外聊天权限；实际发送仍由声音插件及宿主授权控制。

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 配置选项

| 配置 | 默认值 | 范围或选择 | 说明 |
| --- | --- | --- | --- |
| 内置肥鱼语音引擎 | "breeze" | breeze / cosyvoice | Breeze沿用现有语音；CosyVoice3让内置明亮可爱B/温柔使用专用肥鱼权重直接生成，不再经过RVC。自然A和自定义参考仍走Breeze，外接API优先。保存后重启语音服务，新任务使用新选择。 |
| 专用本机服务端口 | 19886 | 1024–65534 | 专用本机服务端口，默认19886；不需要公网地址。更改后重启语音服务，注意不要与Breeze、唱歌或其他程序端口重复。 |
| 允许本机同文本对比试听 | true | 开 / 关 | 开启后可在语音音色页用同一句文字分别生成Breeze和CosyVoice3试听，仅在本机播放，不发微信。即使当前选择Breeze，也会准备Cosy服务并占用部分内存/显存；关闭则禁止对比。 |

## 限制与排查

首次模型加载耗时且占用显存；自定义参考、自然A和外接API沿用各自路径，不自动走专用肥鱼模型。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后从托盘完整重开DSH。
- 模型或本地环境报错：先在对应功能页做连接检测或本机试听，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
