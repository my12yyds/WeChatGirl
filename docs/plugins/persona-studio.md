# AI 人格工作室

版本：1.1.0 · 基础插件，随主包提供

[返回插件目录](README.md) · [下载单独插件包](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.7/persona-studio-1.1.0.zip)

## 适合做什么

编辑与使用人格资料，让不同聊天使用合适的人设。

通过对话设计、修改、预览人格，导出可在新版人格页面导入的 Markdown；不自动更换当前人格。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 在能力目录启用后进入人格页；先选择允许的聊天，再分配人格。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重开DSH。

## 使用例子

先编辑人格说明，再把它分配给测试好友；确认语气后用于群聊。

## 权限与数据

- 保存插件数据
- 独立调用当前模型（会产生消耗）

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 配置选项

本插件没有独立参数；按权限和聊天范围控制。

## 限制与排查

人格资料是提示信息，不应在公开包中包含私人聊天或账号资料。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后从托盘完整重开DSH。
- 模型或本地环境报错：先在对应功能页做连接检测或本机试听，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
