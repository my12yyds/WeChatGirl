# 哔哩哔哩

版本：1.0.0 · 可选插件，按需安装

[返回插件目录](README.md) · [下载单独插件包](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.7/bilibili-public-1.0.0.zip)

## 适合做什么

搜索公开视频、读取哔哩哔哩链接的公开资料。

在聊天里搜B站视频，读取BV号、视频链接和b23短链。获取标题、UP主、简介、分P和可公开读取的字幕，明确区分字幕与简介。无需登录，不操作账号。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 安装并授予公开网络权限，选择聊天后使用。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重开DSH。

## 使用例子

“搜一下某主题的B站视频”，或直接发送BV链接要求介绍。

## 权限与数据

- 访问公开网页

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 配置选项

本插件没有独立参数；按权限和聊天范围控制。

## 限制与排查

仅处理公开可读取内容，不绕过登录、付费或平台限制。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后从托盘完整重开DSH。
- 模型或本地环境报错：先在对应功能页做连接检测或本机试听，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
