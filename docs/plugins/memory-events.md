# 事件与约定

版本：1.2.1 · 可选插件，按需安装

[返回插件目录](README.md) · [下载单独插件包](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.7/memory-events-1.2.1.zip)

## 适合做什么

把本人明确表达的计划与约定保存为带状态的事件。

把本人明确说出的计划与约定记成独立事件，保存参与人、时间、计划中/已完成/已取消状态。参与人使用真实身份核验，同名不合并；未知日期不猜测，完成与取消也需要本人明确说明。仅当前授权人物和聊天可查，不会自动发提醒。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 授权人物记忆与存储，设置计划和关闭事件的保留期限。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重开DSH。

## 使用例子

“记住周六晚上八点一起打游戏”“这件事完成了”“取消那个约定”。

## 权限与数据

- 按真实身份保存跨聊天记忆
- 保存插件数据

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 配置选项

| 配置 | 默认值 | 范围或选择 | 说明 |
| --- | --- | --- | --- |
| 同时记录本人明确事实（默认关闭） | false | 开 / 关 | 默认关闭。开启后额外把本人明确事实交给人物记忆服务记录，需要人物记忆权限；事件记录工具本身不依赖此开关。不会把转述或引用当成本人事实。 |
| 每位人物在当前聊天的事件容量 | 64 | 8–128 | 每位人物在当前聊天最多保存的事件数。达到容量时会拒绝新增，不自动覆盖未完成约定；可先完成、取消或调整容量。 |
| 计划中事件保留天数（新记录） | 30 | 1–365 | 新建计划从记录时间开始的保留天数，默认30天。到期后列表不再显示；修改不批量改写旧记录，也不是自动提醒时间。 |
| 完成或取消后保留天数 | 7 | 1–365 | 明确完成或取消后重新计算保留天数，默认7天。用于保留近期结果，和计划中的保留期限分开。 |

## 限制与排查

不自动发提醒；未知日期不编造，同名不合并，完成和取消需要本人直接证据。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后从托盘完整重开DSH。
- 模型或本地环境报错：先在对应功能页做连接检测或本机试听，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
