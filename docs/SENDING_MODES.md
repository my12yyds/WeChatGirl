# 微信发送模式

在侧栏“发送模式”选择并保存。`wechat.textTransport.mode` 保留 `native` 与 `foreground`，对应 Hook 完整模式与鲸鱼娘前台模式。

| 功能 | 前台 | Hook |
| --- | --- | --- |
| 文字 | 操作微信窗口 | 原生组件发送 |
| 表情 | 随机选一张微信收藏表情 | 4.1.10.27 发送指定原生表情。4.1.15.13 可发送指定表情首帧或随机收藏 |
| 群聊 @ | 普通文字称呼 | 原生提醒，受成员检查及提醒频率限制 |
| 原生语音、歌曲语音 | 不可用 | 组件与音频依赖就绪后可用 |
| 图片、文件及其他 Hook 发送 | 不可用 | 按能力与授权使用 |

前台方法参考既有项目，但在本项目独立实现，不依赖旧项目目录或额外 Python。微信窗口需可操作，发送可能切换聊天；发现同名目标、已有输入草稿或无法确认目标时停止。前台模式阻止 Hook 发送，不在失败时自动回退。

保存影响后续新发送；已提交微信的动作可能继续完成，不承诺撤回。切换只隔离发送，不卸载已经加载的 Hook，也不改变读取方式。

界面保留作者判断：前台方式预计封号概率较低，Hook 回复方便、能力完整但预计风险较高。**这不是经统计验证的概率结论，两种方式都不能保证账号安全。**不要将前台模式描述成“无 Hook”。

“检查前台组件”只核对状态，不发送消息。语音已生成但不能投递时，先检查模式、聊天权限、额度与实际回执。详见[声音工作室](VOICE_STUDIO.md)、[表情管理](STICKER_MANAGER.md)。
