# 表情管理、模式差异与诊断

左侧“表情包”统一提供图库、自动收集、来源与搜索、发送设置。连接当前微信并启动读取服务后，可读取账号图库。

## 导入与编辑

一次可选 1–20 张 GIF、PNG、JPG 或 WebP；单张最多 8 MB、边长 4096 像素、动图 64 帧，所有帧合计最多 8000 万像素。GIF 保留动画，其他格式转换为发送所需 GIF。批量逐张处理，显示单项结果；断连、账号变化或服务不可用时暂停，成功项保留。

手动添加、编辑描述及最多 6 个标签不调用模型，立即保存。点击图片预览动图。删除仅清理账号池副本及引用，保留源文件和聊天记录；已提交的发送可能继续。删除记录暂时阻止自动收集立即加回，重新手动导入可以恢复。

## 共享与上限

手动导入与聊天收集共用当前账号 50 张池，相同图片合并。满池手动导入要求先删除；自动收集的满池评选可能调用模型替换旧项。

微信收集和 DSH 入库分别开启，在“自动收集”中配置。列表显示新素材的微信/DSH 来源；同图可带两个来源，老版本未记录的素材显示历史来源未区分。手动添加继续使用独立的手动标记。

手动资源可用于当前账号已允许聊天；收集资源另受来源、共享开关和聊天范围约束。单聊发送开关始终生效，不同账号不混用。池位于 `state/stickers/collected/`，不进入源码和发行包。

## 发送方式

微信 4.1.10.27 的 Hook 模式可从图库发送指定原生表情。微信 4.1.15.13 的 Hook 模式默认启用“指定表情以静态图片发送”，将所选素材首帧按图片投递，动图会显示为静态图。多表情仍逐项排队，各有投递编号。

微信 4.1.15.13 可在“发送模式”另行启用“兼容发送收藏表情”。先在微信收藏至少一张表情，再保持桌面解锁和微信窗口可操作。兼容发送和鲸鱼娘前台模式均从微信收藏随机选取一张。

原生动图属于微信表情消息（类型 47）。[小鱼的原生 GIF 接口](https://github.com/waaakong/xiaoyu/blob/main/docs/dsh-wechat.md) 对应微信 4.2.0.13。[helper 的 4.1.15.13 原生表情实现](https://github.com/Prometheus-first/helper/blob/119acdf9d74654c6ebb8cded2c6841b85af75867/docs/messages/emoticons.md) 使用与当前内置微信相同的核心指纹，当前 WeChatGirl 的 4.1.15.13 发送组件仍使用上面的两种发送方式。

旧回执不能清除同一 GIF 新任务的待确认记录；不同投递编号不能共用回执。同一 GIF 可在不同回复各发送一次，送达未知时先核验，避免盲目重发。

## 只读检查

点击“检查表情服务”核对读取器、消息桥接、当前模式和图库。若收藏为空、面板打不开、目标有草稿或回执待确认，检查会展示最近错误和处理方法。检查只读取状态。离线时先启动服务，再刷新。

图可预览但未回复时，分别检查模型是否生成回复、聊天是否允许发送及实际发送回执。Hook 组件未就绪、前台目标不明、权限缺失与资源错误不能混为“表情坏了”。外部图库接入见[dsh-meme](DSH_MEME.md)，收集策略见[表情收集](STICKER_COLLECTION.md)。
