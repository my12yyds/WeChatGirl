# WeChatGirl 0.5.7

普通用户下载 Windows 安装版。便携版与安装版任选其一。本版内置微信 4.1.15.13 x64，DSH 独立安装。

## 下载哪个包

| 文件 | 用途 |
| --- | --- |
| `WeChatGirl-Setup-0.5.7-x64.exe` | Windows 10/11 x64 安装版。双击安装，首次使用推荐此包。 |
| `WeChatGirl-0.5.7-portable-x64.zip` | Windows x64 便携版。完整解压，打开根目录的 `WeChatGirl.exe`。 |
| `WeChatGirl-voice-components.zip` | 可选本地语音运行环境。在程序的语音组件管理中导入 ZIP，模型权重按需另行准备。 |

| `RELEASE_NOTES.md` | 版本更新说明。 |

## 本版更新

- 内置微信升级为 4.1.15.13 x64，新安装自动准备匹配客户端、读取 DLL 和发送组件。打包校验腾讯签名、x64 架构及组件哈希。
- 适配 4.1.15.13 原生语音气泡，复用音色、合成、歌曲缓存和分段投递。实测完整语句和四段翻唱，每段服务器回执与 SILK 摘要均匹配。
- 修复 4.1.15.13 登录时发送组件入口栈占用过大导致闪退的问题，独立客户端启动时启用版本保护。
- 接入原生图片发送。在发送模式页可开启 4.1.15.13 前台兼容发送，提供普通文件和随机收藏表情；指定近期文字消息可经桥接接口发送原生引用。窗口不可用、目标或引用预览不匹配时停止。
- 修复新版 DSH 工具清单接口变化导致聊天报错，管理员可在已授权的聊天用 /dsh 交办任务。
- 完整歌曲首段确认送达后提醒点歌人一次，提醒独立于普通群聊艾特冷却。

## 升级与使用

升级前保存设置，从托盘完整退出 WeChatGirl、DSH 和微信，再安装或解压新版。保留原 data 目录。已有安装保留当前微信选择；如仍使用旧版，请在配置向导的版本卡选择“使用并打开内置匹配版”，登录后验证账号再启动服务。

原生语音和图片通过匹配组件投递。普通文件、收藏表情和引用的前台兼容操作需要桌面解锁及微信窗口可用。随机收藏表情需要先在微信收藏；指定图库表情的原生发送仍只在 4.1.10.27 上提供。4.1.15.56 等其他版本不套用本版组件。音色和完整歌曲的听感仍取决于所选模型与源素材。

插件包沿用现有插件版本，宿主适配由主程序升级提供。插件总包会跳过已有插件，新插件默认关闭。语音运行环境与模型通过语音组件页另行导入。
