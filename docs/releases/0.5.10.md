# WeChatGirl 0.5.10

## 下载哪个包

[夸克网盘](https://pan.quark.cn/s/b57dd69d37af) · [GitHub 发布附件](https://github.com/my12yyds/WeChatGirl/releases/tag/v0.5.10)

| 文件 | 用途 |
| --- | --- |
| `WeChatGirl-Setup-0.5.10-x64.exe` | Windows 10/11 x64 安装包，适合首次使用和原位升级。 |
| `WeChatGirl-0.5.10-portable-x64.zip` | 便携版。完整解压后打开根目录的 `WeChatGirl.exe`。 |
| `WeChatGirl-plugins-all-0.5.10.zip` | 可选插件总包，在能力目录一次导入。也可以单独下载所需插件 ZIP。 |
| `WeChatGirl-voice-components.zip` | 可选语音运行组件，在音乐页导入。部分音色和翻唱模型需另外配置。 |
| `SHA256SUMS.txt` | 下载包的 SHA-256 校验值。 |

## 更新内容

- 检查更新、语音组件和插件总包提供两个下载入口，夸克网盘优先。插件总包仍可从 GitHub 一键下载并导入。

- 记忆星图加入群友观察、已保存的聊天摘要和日记。人物、聊天与同日同类事件可关联浏览，超过单批上限的记录可继续翻页。
- 三维星图支持缓慢旋转、俯视、侧视和极简模式。可切换到包含 48 条虚构记录的演示星系。
- 人物记忆可从授权聊天中的明确表述自动记录约定和经历，并在能唯一匹配时更新状态。
- 控制台采用圆角磨砂外框，星图保留左侧导航。

升级前从托盘退出 WeChatGirl，升级时保留原有 `data` 目录。完整重开 DSH 后加载新版记忆代码。星图中的摘要是已保存的本地聊天摘要。
