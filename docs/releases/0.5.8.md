# WeChatGirl 0.5.8

Windows 10/11 x64，内置微信 4.1.15.13。DSH 单独安装。

## 下载哪个包

| 文件 | 用途 |
| --- | --- |
| `WeChatGirl-Setup-0.5.8-x64.exe` | Windows 安装版，首次使用推荐。 |
| `WeChatGirl-0.5.8-portable-x64.zip` | Windows 便携版。完整解压后打开根目录的 `WeChatGirl.exe`。 |
| `WeChatGirl-voice-components.zip` | 可选语音运行组件，在程序内导入。SenseVoice 权重和识别运行库另行准备。 |
| `WeChatGirl-plugins-all-0.5.8.zip` | 16 个插件的合集，在「能力目录」选择「导入插件总包」。 |
| 单个插件 ZIP | 只导入所需功能。版本、用途和配置见 [插件目录](../plugins/README.md)。 |
| `PLUGINS.md`、`RELEASE_NOTES.md` | 插件索引与本版更新说明。 |
| `SHA256SUMS.txt`、`CHECKS.json`、`VERIFICATION.json` | 附件校验与验证记录。 |

## 本版更新

- 视频工作台可在本机压缩为 MP4，或抽帧交给 DSH 识别。可独立搜索、选择识图模型，也可跟随聊天模型与图片分流。
- 微信语音识别支持本机 SenseVoice 和 Whisper，保留外接 API。SenseVoice 在电脑上转写，聊天模型接收文字。[配置说明](../plugins/speech-recognition.md)
- 修复表情候选被误当作识图素材、微信 4.1.15.13 选中表情的首帧发送和回执核对。兼容模式可从微信收藏发送表情。4.1.15.13 的指定原生动图发送尚未接入。
- 本机试听直接返回 WAV。测试微信语音可使用已选的内置或外接音色，连接或发送失败时补充处理提示。

## 升级与使用

升级前保存设置，从托盘完整退出 WeChatGirl 和 DSH，再安装或解压新版。保留原 `data` 目录。重新打开 DSH 后，在控制台确认连接状态。

安装版和便携版内含人物记忆、人格工作室两项基础插件。已有的视频或语音识别插件，请导入对应的新版单独 ZIP 并选择替换。总包跳过已安装插件，新插件默认关闭。在「插件与聊天」按好友或群授权后即可使用。
