# WeChatGirl 0.5.9

适用于 Windows 10/11 x64。内置微信 4.1.15.13，DSH 单独安装。

## 下载哪个包

| 文件 | 用途 |
| --- | --- |
| `WeChatGirl-Setup-0.5.9-x64.exe` | Windows 安装版，首次使用推荐。 |
| `WeChatGirl-0.5.9-portable-x64.zip` | Windows 便携版。完整解压后运行根目录的 `WeChatGirl.exe`。 |
| `WeChatGirl-plugins-all-0.5.9.zip` | 16 个插件的总包，可在「能力目录」导入。 |
| 单个插件 ZIP | 按需安装，见 [插件目录](../plugins/README.md)。 |
| `WeChatGirl-voice-components.zip` | 可选本机语音运行组件。SenseVoice 权重与识别运行库单独安装。 |
| `PLUGINS.md`、`RELEASE_NOTES.md` | 插件索引与本版更新说明。 |
| `SHA256SUMS.txt`、`CHECKS.json`、`VERIFICATION.json` | 附件校验值与验证记录。 |

## 本版更新

- 微信 4.1.15.13 恢复发送指定图库表情。GIF 以微信原生表情（类型 47）发送，保留动画，超出组件尺寸限制时缩小后发送。实测文件传输助手收到匹配的微信服务器回执。
- 修复微信消息桥接丢弃语音的问题。已授权聊天的语音会转写，再交给聊天模型回复。实测真实私聊语音完成转写，并收到自动回复的微信回执。

## 升级步骤

1. 保存设置，从系统托盘完整退出 WeChatGirl、微信和 DSH。
2. 运行新版安装包，或将便携版完整解压到原程序目录。保留原 `data` 目录。
3. 打开 WeChatGirl，连接匹配微信和 DSH，再启动服务。通过「表情包 → 检查表情服务」确认原生表情组件就绪。
4. 语音识别需要安装插件并在「插件与聊天」授权相应好友或群。已有 1.5.0 插件可继续使用，语音接收修复由主程序提供。
