# 微信版本检测与内置匹配版

当前打包默认包含微信 4.1.15.13 x64 及对应发送组件，不需要单独寻找旧版安装包。程序保存在 app；首次启动把匹配微信准备到自己的 data/workspace/state/hook/wechat-4.1.15.13，不替换系统安装的微信。

在“配置向导 → 连接微信”或“设置 → 微信与 DSH”查看微信版本卡。检测覆盖当前配置、内置目录、Windows 常见安装位置、App Paths 和正在运行的微信；只读取程序路径、版本和签名，不读取聊天或账号资料。

点击“使用并打开内置匹配版”后，程序先重新校验客户端 EXE、核心 Weixin.dll、x64 架构、腾讯数字签名和匹配发送组件哈希，再通过原有配置保存和启动流程打开客户端。仅修改对应微信程序位置和预期版本。尚未保存的草稿不会被覆盖；切换客户端前需停止正在使用旧客户端的助手服务。

如果系统微信正在运行，请保存工作并从系统托盘退出后再打开匹配版。程序不强制结束系统微信，不复制其登录资料；匹配版首次使用仍需自行扫码登录，并在向导验证账号。内置文件缺失或版本不符时会禁止启动，重新安装程序时请保留 data。

默认内置微信为 4.1.15.13 x64。已有安装可在版本卡切换到该精确版本。先准备该精确版本的腾讯签名客户端和对应发送组件，见[组件准备](WECHAT_4_1_15_13.md)。在版本卡点击“使用并打开 4.1.15.13”，切换前先停止助手服务并从托盘退出其他微信。登录后在配置向导核验读取账号，再启动服务。切回旧版时使用“使用并打开内置匹配版”。

基础兼容版接入微信读取验证、文字发送、群 @ 和助手图片发送。在已开启文件传输的助手聊天中，可以要求将工作区内的 PNG、JPEG 或 WebP 作为图片发送。

在“微信发送模式”启用“微信 4.1.15.13 兼容发送”后，普通文件和随机收藏表情可尝试经微信窗口发送。保持桌面解锁，发送会切换前台聊天；账号、目标或附件预览校验失败时停止。随机收藏表情需先在微信里收藏，图库指定表情仍需原生发送接口。4.1.15.56 等其他版本只做检测，不套用 4.1.15.13 的发送组件。

更新后的 4.1.15.13 组件提供原生语音发送。它复用当前音色、合成、唱歌、缓存和分段流程，每次启动先核对录音调用入口并执行不发消息的对象构造检查，通过后才报告语音能力。2026-11-07 本机实测向文件传输助手提交了三秒 SILK 测试音，微信显示为原生语音气泡。播放听感需要实际收听确认，完整歌曲仍按原有逐段回执机制投递。

随后实测当前配置音色的一句完整语音（6.32 秒），以及一首缓存的完整翻唱（55、55、55、9.26 秒，共四段）。每段均在文件传输助手取得服务器回执，且读取出的 SILK 摘要与发送前一致。各段确认后才继续下一段，实际音色和音乐听感由收听确认。

OneBot 的文字发送请求可附带 `wechatagent_quote_server_id` 和独立的 `wechatagent_delivery_id`，通过前台兼容通道引用当前会话中可见、正文唯一的近期文字消息。发送前校验引用预览，读取回执时再次比对原消息服务器 ID。普通回复继续按原发送方式处理。

检测有短时缓存，“重新检测”会主动刷新。签名或核心文件校验失败时不会以“找到 EXE”作为成功条件。运行进程、端口、账号和发送组件仍由启动后的现有连接检查再次核验。
