# WeChatGirl · 鲸鱼娘

一个 Windows 微信 AI 助手。给好友或群聊设置人格，让它回复消息、记住聊天内容，也可以通过微信交办已授权的 DSH 任务。

[下载安装](https://github.com/my12yyds/WeChatGirl/releases/latest) · [下载包说明](docs/releases/0.5.7.md#下载哪个包) · [插件目录](docs/plugins/README.md) · [详细教程](docs/GETTING_STARTED.md)

## 快速开始

1. **下载安装。** Windows 10/11 x64 首选 `WeChatGirl-Setup-0.5.7-x64.exe`。便携版请完整解压，再打开根目录的 `WeChatGirl.exe`。
2. **连接微信。** 打开配置向导，按提示启动匹配的微信，登录并验证账号。当前内置微信为 4.1.15.13 x64，支持原生语音和歌曲分段；文件、收藏表情及指定消息引用可启用前台兼容发送。
3. **连接 DSH。** 单独安装或选择已有的 DeepSeek Harness，登录模型账号，按向导导入并启用插件。随后从托盘完整退出并重开 DSH，再选择模型。
4. **试一次回复。** 在「聊天」添加一个允许回复的好友，选好人格和发送模式，应用配置并启动服务。请好友发一句「你好」，确认微信收到回复。

需要语音、翻唱或更多能力时，在「能力 → 能力目录」按需导入插件。升级前先退出程序并保留 `data` 目录。 [安装与升级说明](docs/INSTALLER_RELEASE.md)

## 详细说明

本项目基于 [WeChatAgent](https://github.com/sourcepro5/WeChatAgent) 开发。组件来源与许可见[声明](声明.md)和[第三方许可](LICENSES.md)。

## 功能与入口

| 页面 | 可以做什么 |
| --- | --- |
| 配置向导 | 基础连接检查、发送模式确认、可选功能教程与配置跳转 |
| 工作台 | 启停服务、查看微信与 DSH 状态、诊断和最近动态 |
| 聊天 | 管理允许的好友/群聊，分别设置人格、模型、模式、权限及上下文 |
| 人格 | 导入、编辑、分类和分配人格卡 |
| 能力 | 查看 DSH 工具来源，管理联网与阅读，导入插件及调整参数和权限 |
| 插件与聊天 | 在同一页选择群聊或好友，勾选该聊天可使用的插件；逐项自动保存 |
| 音乐 | 语音组件下载与导入、网易云登录、搜歌、音源检查、曲库、翻唱模式和制作进度 |
| 语音音色 | 语音回复、内置与自定义音色、本机模型、外接 API、Breeze/CosyVoice3 对比与引擎设置 |
| 发送模式 | 选择前台或 Hook 发送，查看整套能力差异 |
| 表情包 | 手动导入、收集、预览、编辑标签、发送设置与只读诊断 |
| 记忆 | 管理人物事实和修改记录，查看群友、日记与摘要，核对运行内核并进行长对话评测 |
| 设置 | 默认行为、管理员、微信与 DSH、图片分流、诊断、日志、外观及数据位置 |

内部页面支持返回上一页。单聊弹窗、插件参数、音色和全局设置各有保存入口；不要把页面跳转当作保存。托盘与右上角更多菜单提供一键启动、重启服务和重启程序。窗口“×”收起到托盘，退出应用会停止本实例服务，保留外部微信与 DSH。详见[界面说明](docs/UI_LAYOUT.md)。

## 两种发送模式

| 能力 | 鲸鱼娘前台 | Hook 完整模式 |
| --- | --- | --- |
| 文字 | 操作微信窗口发送 | 原生组件发送 |
| 表情 | 随机点击当前可见的收藏表情 | 支持指定表情与多表情队列 |
| 群聊 @ | 普通文字称呼 | 支持原生 @，同轮仅第一条文字提醒 |
| 语音气泡、歌曲语音 | 停用 | 组件与音频依赖就绪后可用 |
| 图片、文件等 Hook 发送 | 停用 | 按对应能力与权限使用 |

前台模式需要微信窗口可操作；目标不明确、同名聊天或已有输入草稿等情况会停止发送，不自动改用 Hook。切换只影响发送，不卸载已有 Hook、不改变读取方式。

按作者预期，前台方式封号概率较低，Hook 功能更全、回复方便但封号概率较高；**此判断未经统计验证，两种方式均不保证账号安全**。详见[发送模式](docs/SENDING_MODES.md)。

## 模型、图片与任务权限

DSH 模型列表由当前已连接的 DSH 获取，可按聊天选择。模型可见不代表账号有可用额度。当前聊天模型支持图片时直接使用原图；纯文本模型可先调用备用识图模型，把观察结果交回原聊天模型。模型按能力分组，可搜索并独立测试。解析会使用模型额度，图片中的文字按不可信资料处理。详见[图片分流与测试](docs/IMAGE_UNDERSTANDING.md)。

聊天模式负责人格对话；助手模式负责任务交办。管理员 DSH 插件也可在聊天模式中申请任务，但必须同时满足真实管理员身份、本聊天授权和 DSH 原生权限。普通群友不会继承管理员工具权限。技能、工具与 WeChatGirl ZIP 插件分别管理；安装插件不等于授予执行权限。详见[按聊天授权](docs/DSH_CHAT_ACCESS.md)、[远程助手](docs/ASSISTANT_REMOTE.md)。

## 音乐与语音

音乐页提供网易云站内搜索、二维码及官方窗口登录，并可逐首“检查音源”。**搜得到、登录成功、拥有完整音源权限是三件事**；会员、地区、下架和试听限制按平台结果处理，不替换为错误歌曲或绕过限制。公开搜索与 B 站阅读说明见[公开媒体](docs/PUBLIC_MEDIA.md)，登录排障见[网易云账号](docs/NETEASE_ACCOUNT.md)。

语音默认调用本机部署的 Breeze 服务，肥鱼变声、唱歌和分离伴奏需相应本地组件与模型。音乐页可管理内置/自定义音色、随机音色、部分句子随机改发语音、发送节奏、人声清晰度与伴奏音量。自定义参考音色用于说话；唱歌继续使用已安装的翻唱模型。

用户可主动切换到兼容 `/audio/speech`、返回 WAV 的外接语音 API。该模式会向所填服务发送待合成文字，可能产生费用；本地参考录音不上传。密钥由 Windows 当前账户加密保存。

歌曲制作支持已有曲库、按歌曲名匹配授权音源后分离伴奏并换声，以及歌词配曲谱演唱。完成作品保存在本机，满足账号、歌曲、音色和参数条件时直接复用。界面显示实际制作、排队与发送阶段；“生成完成”不代表微信已送达。前台模式不能发送语音气泡。**插件 ZIP 和语音运行组件不等于完整模型包**，新电脑需另行准备模型及许可。详见[声音工作室](docs/VOICE_STUDIO.md)。

## 表情与记忆

表情页支持批量导入、动图预览、标签编辑、账号内共享池和只读服务检查。共享池上限 50 张，收集范围和单聊发送开关分别生效。多表情使用独立投递编号；送达未知时核验回执，避免盲目重发。详见[表情管理](docs/STICKER_MANAGER.md)。

群友互动记忆按群隔离；人物记忆插件保存本人明确事实，默认仅在原聊天使用，明确同意后才跨聊天召回。二者与上下文压缩摘要、人格卡和日记分别管理，不根据同名推断同一个人。基础聊天保留近期原文；启用人物记忆插件并授权到聊天后，可自动补充旧事实、相关档案片段和已有摘要，后台整理窗口外的历史。人物记忆插件 1.2.0 可按组调整记录类别、共享、召回预算、近期窗口、保留期限与后台摘要，入口为“记忆 → 人物与事实 → 记忆插件设置”。详见[记忆内核](docs/MEMORY_CORE.md)、[人物记忆](optional-extensions/people-memory/README.md)、[群友记忆](docs/MEMBER_MEMORY.md)。

## 升级与数据

同目录升级保留配置、人格、用户插件和运行状态；升级前保存草稿并退出旧程序。涉及 DSH 插件更新时从托盘完整退出并重新打开 DSH。移动安装位置前确认数据来源和目标，不直接覆盖用户目录。卸载保留用户数据，清理数据需另外操作。

`config/wechatagent.json`、`host: "wechatagent"`、`/WeChatAgent/*` 等旧名称属于配置与协议兼容项，不是另一套产品。上游署名和历史记录也保留原名。详见[品牌兼容](docs/BRANDING.md)、[数据管理](docs/DATA_STORAGE.md)、[安装说明](docs/INSTALLER_RELEASE.md)。

## 开发与维护

从[根目录维护指南](PROJECT_GUIDE.md)开始，按[目录边界](docs/PROJECT_LAYOUT.md)和[迭代流程](docs/ITERATION_WORKFLOW.md)修改源码。规划见[路线图](docs/ROADMAP.md)，变更见[更新日志](RELEASE_NOTES.md)，构建与上传见[发行流程](docs/RELEASE_WORKFLOW.md)。

源码不包含用户账号、凭据、聊天数据库、完整模型或完整二进制工具链。Windows 打包脚本依赖经过审计的发行基线，不能将其描述为任意电脑克隆仓库即可完整重建。

```powershell
node --test --test-reporter=spec scripts/test-*.mjs
node scripts/plugin-host-check.mjs --root .
git diff --check
```

测试使用隔离数据，不自动向真实聊天发送消息。源码和发行附件位于 [my12yyds/WeChatGirl](https://github.com/my12yyds/WeChatGirl)；仓库及发行附件公开可访问，可从 Releases 下载；程序通过公开发行接口检查更新。

语音读取与编解码回归需要 Python。未安装全局 Python 时，先把 `WECHATAGENT_TEST_PYTHON` 和 `VOICE_TEST_PYTHON` 指向发行版自带的 python.exe，再运行上述测试。
