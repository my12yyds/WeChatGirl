# 视频压缩与识别

1. 在 WeChatGirl「能力目录」导入 ZIP。打开插件配置，启用插件，勾选允许的好友或群聊并保存。
2. 再次打开配置中的「视频工作台」，选择聊天和本机视频。支持 32 MB、3 分钟以内的 MP4、MOV、M4V、WebM 和 MKV。
3. 点击「压缩为 MP4」后可下载成品。压缩在本机进行，使用 H.264 和 AAC，保留首条音轨。缺少 FFmpeg 时，在「语音音色」导入语音组件。
4. 在「视频识别模型」选择 DSH 目录里的独立识图模型并保存，或选择跟随聊天与图片分流。点击「识别视频画面」后，程序会把按顺序排列的抽帧拼图交给模型。结果显示在工作台，可用于了解画面、动作和可见文字。

识别可能使用模型额度。模型接收抽帧拼图；原视频只在本机处理。当前分析范围是抽取的画面，声音、字幕轨和帧间细节需要另行核对。压缩和识别均由用户在工作台发起。

抽帧方法参考 [AstrBot 视频上下文插件](https://github.com/ZAKOsiesta/astrbot_plugin_video_context)。编码与容器处理使用本机 [FFmpeg](https://ffmpeg.org/ffmpeg.html)。
